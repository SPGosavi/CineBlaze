# Phase 5 Eval Harness

This folder contains the Phase 5.0 retrieval-quality harness.

## Files

- `queries.json` — curated known-answer eval set (title / plot / generic / franchise / regional / recommend).
- `run.ts` — executes the eval in-process against controller logic and writes metrics.
- `results/*.json` — timestamped outputs (generated by the script).

## Run

From repo root:

```bash
npm run eval:run -w movie-finder-backend
```

Create/refresh a baseline run:

```bash
npm run eval:run -w movie-finder-backend -- --baseline
```

## Output metrics

- `hit@1`, `hit@3`
- latency p50/p95
- `resolvedBy` branch distribution
- prompt/completion token totals and averages
- grounding source contribution (chars, populated source count)

Each run writes `backend/eval/results/run-<timestamp>.json` (or `baseline-...`) and prints summary + diff vs previous saved run.
